# Green House monitoring System 

## Overview 

- This software will monitor and visualized each designed zone display its envirment metrics
such as temperature, humidity , pH levels acrros designed zones of the greenhouse 

- The system will provide dashboards that will allow the user monitor
real time conditions of plants and adjusting as need it

### Project goals 
- Monitor environmental conditions across multiple green house zone 
- Provide dashboad for data visualization 
- Detection of different conditions of the zone 
- Dosing of a system that can interact with physical sensors using raspberry pi
